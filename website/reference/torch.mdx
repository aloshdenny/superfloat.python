| Name | Description |
|---|---|
| `sft.quantize(t, dtype="sf16", scale=None)` | Fake quantization: values snapped to the SF grid, float storage, same codes and events as `sf.asarray`, straight-through gradient. `scale=None` (values must fit), `"dynamic"` (per call) or a float. |
| `sft.to_sf(t, dtype="sf16", device="host")` | Tensor to `SFArray`. |
| `sft.from_sf(a, dtype=torch.float32)` | `SFArray` or scalar to tensor (float32 holds every width exactly). |
| `sft.linear(x, weight, bias=None, dtype="sf16", scale="per_tensor", headroom="bound", name="linear", *, accumulate="chain", shift=None)` | Functional chip-exact SF linear. `accumulate="wide"`: the MX engine with the wide-mode shift rule. |
| `sft.matmul(a, b, dtype="sf16", headroom="bound", name="matmul", *, accumulate="chain", shift=None)` | Functional chip-exact SF matmul of two activations. |
| `sft.attention(q, k, v, attn_mask=None, dropout_p=0.0, is_causal=False, scale=None, enable_gqa=False, *, name="attention")` | `F.scaled_dot_product_attention` with both matmuls on the MX engine at sf16 (ops `sf::matmul_wide` and `sf::matmul_wide_pv`); softmax in float. Statuses `{name}.scores` and `{name}.pv`. |
| `sft.SFLinear(in_features, out_features, bias=True, *, dtype="sf16", scale="per_tensor", headroom="bound", accumulate="chain", shift=None, name="")` | `nn.Linear` with SF arithmetic. `SFLinear.from_float(linear)` wraps an existing layer's parameters. |
| `sft.SFConv2d(conv, name, cfg)` | `nn.Conv2d` (groups=1, zero padding) as unfold + SF linear. |
| `sft.SFHFConv1D(conv, name, cfg)` | Hugging Face's `Conv1D` (GPT-2's layers): a linear layer with the weight stored `(in, out)`. Same SF maths as `SFLinear`; keeps the source layer's parameter objects. |
| `sft.convert(model, dtype="sf16", scale="per_tensor", headroom="bound", inplace=False, *, accumulate="chain", shift=None, calibration="heuristic", keep_sf16="auto", attention="auto")` | `attention="auto"`: with `accumulate="wide"`, the model's `F.scaled_dot_product_attention` runs through `sft.attention`; `False` leaves it in float. `keep_sf16`: with a dtype below sf16, the layers kept at sf16: `"auto"` (the LM head, `sft.find_lm_heads`), `False`, or a list of names; listed in `ConversionReport.kept_sf16`. Swap every `nn.Linear`, `nn.Conv2d` and Hugging Face `Conv1D` for the SF versions; everything else stays float. |
| `sft.conversion_report(model)` | `ConversionReport(converted, skipped, shared)`. |
| `sft.autocast(dtype="sf16", scale=, headroom=, prefix="autocast.", *, accumulate="chain", shift=None)` | Context manager / decorator routing `F.linear`, `F.conv2d`, `matmul`, `@`, `mm`, `bmm` to the SF ops. |
| `torch.compile(model, backend="superfloat")` | SF nodes run through the Stage 1.1 heavy-op path on `default_device`; the rest stays on CPU. Inference only. |
| `sft.compile_report()`, `sft.compile_reports()` | `GraphReport(on_device, host_emulated, cpu, unconverted)` for the last / all compiled graphs. |
| `sft.last_status(model=None)` | Most recent `SFLayerStatus` per layer name. |
| `sft.capture_status()` | Context manager collecting the statuses of one request (thread / task local). |
| `sft.reset_status()` | Clear the registry. |
| `sft.SFConfig(bits=16, scale="per_tensor", headroom="bound", accumulate="chain", shift=None, calibration="heuristic")` | The scale policy record. `calibration` has one value, `"heuristic"`. |
| `SFLayerStatus` wide fields | `accumulate`, `shift_min`, `shift_max`, `h`, `redone`, `flushed` (`None` on a device), `acc_clipped`, `guard_raised`. In wide mode `underflow` equals `flushed` and `headroom_bits` is 0. |

Scale policy: `scale` is `"per_tensor"` or `"per_channel"` for weights;
activations get a dynamic per-call scale. `headroom="bound"` raises the
activation scale until the L1 bound proves nothing in the layer can
saturate (bits given up are reported as `headroom_bits`); `"none"` uses the
raw scale.

Wide mode (`accumulate="wide"`): power-of-two exponents, one per token for
activations and one per output channel for weights. Every shift comes from
`sf._heuristic` (`h_for`, `plan`), with a redo at `l2` for outputs at
±max. `scale` and `headroom` do not apply. The bias is added in float after POP.
