# Developer docs site

Generated by `python tools/build_site.py` from `README.md`, `docs/*.md`, `NOTES.md`
and `examples/`. Do not edit the `.mdx` files by hand; edit the markdown and
rebuild. CI fails if this folder is out of date.

Preview locally: `npm i -g mint && cd website && mint dev` (http://localhost:3000).

Deploy: connect the GitHub repo in the Mintlify dashboard and set the docs
directory to `website`; every push to `main` redeploys. Point `docs.superfloat.si`
(or a `/docs` path behind a proxy) at it from the dashboard's custom domain settings.
